# Security Policy

## Supported versions

crocotiger is pre-1.0 (`0.x`) — only the latest released version is supported.
There's no formal versioning policy yet; see [CONTRIBUTING.md](./CONTRIBUTING.md).

## Reporting a vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Email **security@tekdatum.com** with:

- A description of the vulnerability and the potential impact
- Steps to reproduce (include a minimal code sample if possible)
- The version(s) of crocotiger affected

You will receive an acknowledgement within **48 hours** and a resolution
timeline within **7 business days**.

We request that you do not publicly disclose the vulnerability until we have
had a chance to release a fix. We will credit you in the release notes unless
you request otherwise.
